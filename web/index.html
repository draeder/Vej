Write some state, ask a question about it, and press ⌘↵.

Each outcome becomes a claim about your state, and the answer is read off how far the model thinks the state entails it — a probability distribution, not a sentence to parse back. It takes milliseconds.

Node server asks the process serving this page. In this browser downloads the model and runs it here on WebGPU — slow the first time, cached after that.
